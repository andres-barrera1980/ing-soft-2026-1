## Instrucciones de entrega

1. Completa cada archivo `respuesta.md` siguiendo la plantilla provista.
2. Haz **al menos 2 commits por pregunta**: uno con el prompt + respuesta del LLM, otro con el análisis.
3. Asegúrate de que el último commit antes de la fecha límite tiene TODAS las preguntas completas.
4. Haz push de esta rama a `origin`.
